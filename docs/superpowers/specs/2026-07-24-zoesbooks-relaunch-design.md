# zoesbooks.com Relaunch — Design Spec

**Date:** 2026-07-24
**Project:** `zoe-roberts-writes`
**Target:** https://zoesbooks.com (Vercel)

## Context

The site promotes one book: *Power-Up Your Mind: Growth Mindset Strategies and Activities for Tweens* by Zoe Roberts, aimed at readers aged 8–12.

It was generated by Lovable and never finished. The toolchain is healthy — TypeScript compiles clean, `npm run build` succeeds in ~7s, the dev server runs. The problem is the content: roughly 70% of the site is generated placeholder fiction describing an author who does not exist, and every form silently discards its input.

## Goal

**The site's primary job is building an email list.** The book sells on Amazon; the site's job is converting parent, teacher, and counselor traffic into subscribers Zoe owns, so she has an audience for her next book.

Amazon purchase links are the secondary action, not the primary one.

## Audience

The distinction that drives every design decision:

- **Reader:** a 10-year-old.
- **Buyer and subscriber:** a parent, teacher, or school counselor evaluating whether Zoe is credible enough to hand to their kid.

The site sells to the adult. The cover art supplies the fun; the site supplies the trust.

## Decisions

| Decision | Choice | Rationale |
|---|---|---|
| Rebuild scope | Rebuild in place | Same end state as a scratch build, keeps git history, site stays buildable throughout |
| Visual direction | Warm & credible | White canvas, book's yellow as accent, friendly sans. Speaks to the buying adult |
| Primary CTA | Email capture | Follows from the list-building goal |
| Email service | Kit (ConvertKit), free to 10k | Double opt-in + automation delivers the lead magnet |
| Contact form | Formspree | No backend needed on static hosting |
| Lead magnet | Existing PDF from Zoe | Real asset already exists |
| Mindset quiz | Kept, feeds the same list | Best code Lovable produced; strong conversion mechanic |
| Languages | English at launch | ES/FR/IT/PT infrastructure preserved, enabled as real translations arrive |
| Host | Vercel | Static SPA, custom domain |

## Non-Goals

- Migrating to Astro. Better for SEO, but would mean rebuilding the i18n work. Revisit as a separate project if organic search becomes the priority.
- Machine-translating the new marketing copy into four languages.
- E-commerce. All purchases go through Amazon.
- A blog or CMS.

## Content Integrity — Mandatory Removals

This is the reason the site cannot ship as-is. All of the following are fabrications published under a real person's name and **must be removed before launch**.

### Fabricated biography

`src/pages/About.tsx` and all five `translation.json` files (`about.bio1`, `about.bio2`, `footer.about`) claim:

- Wins for **the National Book Critics Circle Award and the PEN/Faulkner Award for Fiction**
- An MFA in Creative Writing from the University of Washington
- A national bestselling 2017 novel, *Beneath Quiet Waters*
- A short story collection, *Threadbare*, and "three additional novels"
- Biographical detail: Pacific Northwest upbringing, a studio overlooking Puget Sound, two rescue dogs

None of it is true. The award claims are the most serious item on this list.

### Stock photo presented as the author

`src/pages/About.tsx:21` loads Unsplash `photo-1649972904349-6e44c42644a7` — a photograph of an unrelated person — captioned "Zoe Roberts."

### Fabricated testimonials

`src/components/Testimonials.tsx` carries five detailed endorsements attributed to named professionals with credentials (Melissa J. Klein M.Ed.; Dr. Alex Raines PsyD; Robert T. Fields MS; Jessica Morales; Dana K.). Confirmed generated. Replaced with real Amazon reviews.

### Fabricated free resources

`src/pages/Freebies.tsx` lists six downloads, all `downloadLink: "#"`, promoting books that do not exist: *The Echo of Silence*, *Whispers in the Garden*, *The Moonlight Adventurers*, *The Lighthouse Keeper's Daughter*, *The Memory Collector*.

The featured offer is **"Download Chapter 1 of *Power of Habit*"**, described as "My #1 New York Times bestselling book." *The Power of Habit* is Charles Duhigg's book. This one is not merely false — it claims authorship of someone else's work.

### Fabricated contact details

`src/pages/Contact.tsx` lists a literary agent ("Literary Representation, Inc."), phone `+1 (212) 555-1234`, and "P.O. Box 1234, Seattle, WA 98101". Social links across About, Contact, and Footer point at the bare homepages of facebook.com, twitter.com, and instagram.com.

### Wrong domain throughout

`contact@zoeroberts.com` appears in three files; `og:url` is `https://zoeroberts.com`; `twitter:site` is `@zoeroberts`. The actual domain is **zoesbooks.com**.

## Architecture

### Content model

Book data is currently duplicated across `Books.tsx`, `FeaturedBooks.tsx`, and `bookCovers.ts`, with conflicting values — the publication year is 2023 in one file and 2025 in another, and the descriptions differ. Replaced with a single source of truth:

```
src/content/
  book.ts       — title, subtitle, description, year, cover map by language,
                  Amazon links by region
  reviews.ts    — real Amazon reviews: reviewer, rating, text
  site.ts       — domain, social URLs, contact email, Kit form ID, Formspree ID
```

Every component reads from these. No content literals in components.

### Pages

| Route | Job |
|---|---|
| `/` | Hook + email capture above the fold. Book, real reviews, secondary Amazon link below. |
| `/free-guide` | The point of the site. One real PDF, one form, plus the quiz. Own URL so it can be linked from socials and Amazon back matter. |
| `/book` | Full description, cover, regional Amazon buttons, reviews. For the ready buyer. |
| `/about` | Real bio, real photo. Credibility. |
| `/contact` | Working Formspree form. School visits, media, speaking. |

`/books` and `/events` redirect to `/book` and `/free-guide` to preserve any existing inbound links.

### Deletions

- `src/pages/Events.tsx` — 135 lines, unreachable behind a redirect
- `cdn.gpteng.co/gptengineer.js` script tag in `index.html`
- `lovable-tagger` devDependency and its `vite.config.ts` plugin entry
- `recharts` and `src/components/ui/chart.tsx` — imported by nothing
- Unused shadcn components in `src/components/ui/` (~40 files; audit imports before deleting)
- `bun.lockb` — with both lockfiles present Vercel selects bun while local testing uses npm
- Package rename: `vite_react_shadcn_ts` → `zoesbooks`

## Design System

Replaces the navy/gold/serif "literary fiction" theme, which was generated to match the fabricated novelist persona.

### Color

| Token | Value | Use |
|---|---|---|
| `ink` | `#16324F` | Headings, primary text, buttons |
| `sunshine` | `#FFC72C` | Accent, highlights, CTA emphasis — sampled from the cover |
| `hero-blue` | `#1A4D8F` | Secondary accent — the cover's lettering blue |
| `slate` | `#4A5568` | Body copy |
| `paper` | `#FFFFFF` | Page background |
| `paper-warm` | `#FFFDF8` | Alternating section background |

Removes `cream`, `navy`, `gold`, `soft-gold`, `light-navy` from `tailwind.config.ts`, and updates the shadcn HSL custom properties in `src/index.css` to match.

### Typography

- **Headings:** Nunito 700/800 — rounded and warm without being childish
- **Body:** Inter 400/500

Self-hosted via `@fontsource/nunito` and `@fontsource/inter`. This replaces the Google Fonts `@import` at `src/index.css:1`, which is render-blocking, loads fifteen weights of Playfair Display that will no longer be used, and sends every visitor's IP to Google — relevant given the intended EU audience.

Removes the dead `preconnect` hints in `index.html` (they point at Google Fonts but no font is ever loaded from the document).

## Forms and Integrations

Both endpoints are designed for public HTML form posts, so **no API keys ship in the bundle**.

### Kit (email capture)

`POST https://app.kit.com/forms/{VITE_KIT_FORM_ID}/subscriptions`

Kit handles double opt-in and runs the automation that emails the PDF. Two entry points share one form ID, one list, one automation:

1. The Free Guide page form
2. The quiz result screen

### Formspree (contact)

`POST https://formspree.io/f/{VITE_FORMSPREE_ID}` — emails Zoe.

### Error handling

The current behavior is the most serious functional defect: `Contact.tsx:37`, `NewsletterBanner.tsx:25`, and `Freebies.tsx:178` all display a success toast while discarding the submission. `Footer.tsx:53` has no submit handler at all, so the form reloads the page.

Replacement rules, applying to every form:

- Success shows **only** on a 2xx response.
- Failures show a real error message plus a `mailto:` fallback.
- A missing or empty `VITE_KIT_FORM_ID` / `VITE_FORMSPREE_ID` renders a visible configuration error in development and disables the submit button — it never silently pretends to succeed.
- Fixes the DOM bug at `Freebies.tsx:263`, where `document.querySelector('input[type="email"]')` reads the first email input on the page rather than the one in the submitted card.

## Internationalization

Infrastructure is sound and stays as-is: `i18next` + `HttpBackend` + `LanguageDetector`, loading from `/locales/{lng}/translation.json`.

Changes:

- All five translation files are rewritten against the new copy. The current files translate the fabricated bio, including the fake awards, into four languages.
- `src/content/site.ts` exports `ENABLED_LANGUAGES`. At launch this is `['en']`, and the `LanguageSwitcher` renders only enabled languages. It hides itself entirely when only one is enabled.
- `supportedLngs` in `src/i18n.ts` derives from `ENABLED_LANGUAGES`.
- Localized book covers and regional Amazon lockups are untouched and remain wired.

Enabling a language later is a one-line change plus a reviewed translation file.

## SEO and Metadata

- `og:image` currently points at `https://lovable.dev/opengraph-image-p98pqg.png` — Lovable's default, meaning every social share displays Lovable branding. Replaced with a 1200×630 card composed from the existing book cover art, the title, and the byline, committed as a static asset at `public/images/og-card.png`.
- Title and description currently read "Award-Winning Author … literary fiction" — wrong genre and repeats the fabricated award claim.
- `og:url` and canonical corrected to zoesbooks.com. `twitter:site` is currently `@zoeroberts`, which is unverified; it is removed unless Zoe confirms the handle (see Required Inputs).
- Add `sitemap.xml`.
- Per-route titles and descriptions.

## Deployment

`vercel.json`:

```json
{ "rewrites": [{ "source": "/(.*)", "destination": "/index.html" }] }
```

Without this, `zoesbooks.com/book` returns 404 on direct load even though in-app navigation works. This is the single most common Vite-SPA-on-Vercel failure.

- Framework preset: Vite. Build: `npm run build`. Output: `dist`.
- Environment variables `VITE_KIT_FORM_ID` and `VITE_FORMSPREE_ID` set in the Vercel dashboard for all environments.
- Domain: zoesbooks.com via Vercel DNS. Currently registered with nothing deployed.

## Required Inputs

Implementation can begin immediately; these gate launch, not the work. Each has a defined interim state so nothing blocks.

| Input | Needed for | Interim state |
|---|---|---|
| Zoe's real bio | `/about` | Section renders from `content/`, marked clearly incomplete; no fabricated text |
| Zoe's portrait | `/about`, `/` | Book cover stands in, with honest alt text |
| The lead magnet PDF | Kit automation | Form and list work; Kit automation attaches the file when supplied |
| Real Amazon reviews | `/`, `/book` | Reviews section renders from `reviews.ts`; hidden while empty |
| Real social URLs and X/Twitter handle | Footer, About, Contact, `twitter:site` | Icons omitted rather than linked to bare homepages; `twitter:site` tag omitted |
| Kit form ID | Email capture | Submit disabled, visible config error in dev |
| Formspree form ID | Contact | Submit disabled, visible config error in dev |
| Zoe's contact email | Contact, footer | Placeholder omitted rather than shown as `contact@zoeroberts.com` |

**Nothing renders a fabricated value as a stand-in.** Missing content is either omitted or visibly marked, never invented.

## Verification

1. `npx tsc --noEmit` clean.
2. `npm run build` succeeds; bundle measurably smaller than the current 633 KB / 202 KB gzip. Removing `recharts` and the unused shadcn components accounts for most of the reduction. `framer-motion` is retained — it drives the existing scroll and entrance animations, which carry over.
3. Every route loads by direct URL against `vercel preview` — this is what catches a missing rewrite rule.
4. `grep` the source for each fabricated string in the Content Integrity section; all must return zero hits outside git history.
5. Each form submitted against a real endpoint: success path confirmed, and failure path confirmed by submitting with a deliberately invalid ID.
6. Confirm a test subscription arrives in Kit and the automated email delivers the PDF.
7. Responsive check at 375px, 768px, 1440px.
8. Social card verified with a share-preview debugger.
